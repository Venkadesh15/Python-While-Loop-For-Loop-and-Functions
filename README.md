
# 🐍 Python : While Loop, For Loop and Functions

## 📌 Project Overview
This project contains three beginner-friendly Python programs to practice loops, control statements, and functions through practical examples.

## 🎯 Project Objectives
- 🔄 Understand `while` and `for` loops.
- 🎮 Implement control statements such as `break`, `continue`, `else`, and `pass`.
- ⚙️ Create and use Python functions.
- ⌨️ Accept user input and process data.
- 🧠 Strengthen Python programming fundamentals.

## 🛠️ Tools & Technologies
- 🐍 Python
- 💻 Visual Studio Code (VS Code)
- 🐙 GitHub

## 📂 Programs Included

### 1️⃣ Number Guessing Game 🎯
**Concepts:** `while`, `if`, `elif`, `else`, `break`, `continue`

- 🎲 Generates a random number between 1 and 10.
- 🔢 Allows three valid guesses.
- 📈 Provides feedback when the guess is too high or too low.
- ⏭️ Uses `continue` for out-of-range guesses.
- 🛑 Uses `break` when the correct number is guessed.
- 🔁 Uses `while...else` when all attempts are used.

### 2️⃣ Multiplication Table Generator ✖️
**Concepts:** `for` loop, `range()`, arithmetic operations

- ⌨️ Accepts a number from the user.
- 🔢 Generates the multiplication table from 1 to 10.
- 📊 Displays the multiplication results in a clear format.

### 3️⃣ BMI Calculator ⚖️
**Concepts:** Functions, parameters, `return`, user input

- 📏 Accepts weight in kilograms and height in meters.
- 🧮 Calculates Body Mass Index (BMI).
- 📌 Displays the result rounded to two decimal places.

**Formula:**

BMI = Weight (kg) / Height (m)²

```bash
py "Python While Loop.py"
py "Python For Loop.py"
py "Python Functions.py"
```
